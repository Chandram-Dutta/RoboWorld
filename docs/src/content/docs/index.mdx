<CardGrid>
	<Card title="Build robots" icon="puzzle">
		Start from a template, change it in a few numbers, and let RoboWorld compile, check and
		version the design. Or bring your own MJCF model.
	</Card>
	<Card title="Control them with RoboLang" icon="pencil">
		A small, typed YAML language for poses, keyframes, gaits and closed-loop skills. Robots
		walk without any training: motion compiles to inverse kinematics and balance control.
	</Card>
	<Card title="Plug in any brain" icon="random">
		The robot is an MCP server. Your own harness, an agent CLI or any MCP client can drive it,
		with no dependency on one model vendor.
	</Card>
	<Card title="Measure honestly" icon="approve-check">
		Brains only see what the robot's camera has seen. The simulator judges success from ground
		truth and reports when a brain claims a success that didn't happen.
	</Card>
</CardGrid>

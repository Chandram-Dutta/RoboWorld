# RoboWorld documentation

The RoboWorld documentation site, built with [Astro Starlight](https://starlight.astro.build).

```sh
npm install
npm run dev       # live preview at http://localhost:4321/RoboWorld/
npm run build     # production build in dist/; fails on broken internal links
npm run preview   # serve the production build
```

- Pages: `src/content/docs/` (Markdown and MDX)
- Sidebar and site settings: `astro.config.mjs`
- Theme colours: `src/styles/theme.css`

See the "Development setup" page under Contributing for how to work on the docs.
